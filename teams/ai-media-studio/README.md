# AI Media Studio

Turn a brief into finished images and short videos, with every paid generation approved first.

## Bot

- **Studio — Image and Video Producer**

## Skills

- **image-generation:** Generate or edit images through the MuAPI MCP tools, with the model chosen from search and the prompt approved before spending credits.
- **video-generation:** Generate short videos from text or from a still image through the MuAPI MCP tools, confirming length, model and cost before spending credits.

Add it in MausBot with Import… and this folder's link. Routines arrive paused, and you connect your own apps.
