## Skills

- **destoon-prototype:** [DEPRECATED] 已棄用，請改用 mycms-prototype。原版 Destoon 原型設計技能。
- **destoon-template-convert:** [DEPRECATED] 已棄用，請改用 mycms-template-convert。原版 Destoon 模板套版技能。
- **find-skills:** Helps users discover and install agent skills when they ask questions like "how do I do X", "find a skill for X", "is there a skill that can...", or express interest in extending capabilities. This skill should be used when the user is looking for functionality that might exist as an installable skill.
- **modura-ui:** Modura 前台 UI 開發。觸發：做頁面、寫模板、UI 元件、新增元件、前台頁面、套版、blade 模板、建立頁面、修改頁面、元件庫
- **mycms-engineer:** MyCMS 總工程師。觸發：模組開發、新增模組、系統開發、系統架構、常數變數、tag 標籤、資料庫結構、class 類別、模組安裝、模組設定、CRUD、前台頁面、後台頁面、API 開發、模板開發、chip 元件、tag 模板、模板規範、metadata 格式、自訂欄位、搜尋功能、URL 路由、slug、安全架構、CSRF、認證、前端技術、UI 設計、多語系、FAQ、第三方整合
- **mycms-preset:** Use when the user wants to create a MyCMS site initialization preset for a specific industry or business type. Triggers - 建立預設方案、新增行業方案、preset、初始化方案、建站方案、幫我做 * 的方案
- **mycms-prototype:** 建立 MyCMS 頁面原型。觸發：做原型、設計原型、新增原型、prototype、原型頁面、幫我做 * 原型
- **mycms-template-convert:** 將原型頁面套版為 MyCMS .htm 模板。觸發：套版、新模板、convert template、模板套版、原型轉模板、幫我做 *.htm
- **mycms-template-dev:** [DEPRECATED] 已棄用，模板開發規範已合併至 mycms-engineer。觸發：新增 chip、chip 元件、tag 模板、模板規範、metadata 格式、chip 搜尋
- **openspec-apply-change:** Implement tasks from an OpenSpec change. Use when the user wants to start implementing, continue implementation, or work through tasks.
- **openspec-archive-change:** Archive a completed change in the experimental workflow. Use when the user wants to finalize and archive a change after implementation is complete.
- **openspec-explore:** Enter explore mode - a thinking partner for exploring ideas, investigating problems, and clarifying requirements. Use when the user wants to think through something before or during a change.
- **openspec-propose:** Propose a new change with all artifacts generated in one step. Use when the user wants to quickly describe what they want to build and get a complete proposal with design, specs, and tasks ready for implementation.
- **xampp-index:** XAMPP 站台管理 — 開啟站台、關閉站台、更新首頁。當使用者提到 XAMPP、虛擬主機、本地開發站台、vhosts、開啟站台、關閉站台、更新首頁、mkcert、SSL 憑證、.test 網域，或任何與本地 Apache 虛擬主機管理相關的操作時，務必使用此技能。即使使用者只是問「怎麼新增一個本地網站」或「幫我設定一個 .test 網域」，也應觸發此技能。
