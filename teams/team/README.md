## Skills

- **bot-team-design-and-dispatch:** Design sub-bots and edit the assistant's own role profile.
- **composio-account-connect:** Connect user accounts to Composio toolkits via auth configs.
- **onboarding-capability-audit:** Audit connected apps and rank work to delegate.
- **social-content-reading:** Read public social posts when platform API is blocked.
- **tool-replacement-evaluation:** Decide whether to replace an installed CLI tool with a better one.
- **windows-app-install:** Install Windows desktop apps and verify they run.
- **windows-popup-diagnosis:** Diagnose and stop recurring popup windows on Windows.

Add it in MausBot with Import… and this folder's link. Routines arrive paused, and you connect your own apps.
