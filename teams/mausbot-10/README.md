- **MausBot**

## Skills

- **api-anything:** Get data from a website through its own requests instead of a browser or web search, from a shared catalog or by learning a missing operation in one call. Use when the user wants data or an action from a website ("what does Goodreads rate X", "flights from A to B"), or asks to turn a site into an API.
- **graphify:** Use for any question about a codebase, its architecture, file relationships, or project content — especially when graphify-out/ exists, where the question should be treated as a graphify query first. Turns any input (code, docs, papers, images, videos) into a persistent knowledge graph with god nodes, community detection, and query/path/explain tools.
- **saved-reels-to-skill:** Use when the user wants to go through their Instagram saved reels, saved posts, Instagram data export, or creator DM guides and turn them into something they use. Also use for "doomscroll my saves", "transcribe my saved reels", "what's worth keeping in my saved", or "turn my saved reels into a skill".

Add it in MausBot with Import… and this folder's link. Routines arrive paused, and you connect your own apps.
