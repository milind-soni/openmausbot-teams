# SM

## Bot

- **SM**

## Skills

- **browser-business-navigation:** 使用浏览器进入业务页面并核实列表加载结果。
- **project-purpose-review:** 审查本地项目用途、业务流程和模块职责。
- **wt-dev:** Use when a Scrum Master is asked to coordinate a backend feature or bug fix from a 禅道 task through requirements, development, QA, API documentation and a local Git commit, or to resume a previously recorded stage.

Add it in MausBot with Import… and this folder's link. Routines arrive paused, and you connect your own apps.
