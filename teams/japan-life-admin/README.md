# Japan Life Admin

A two-bot desk for life in Japan: a morning weather and safety brief, then rule-based life admin errands with cited public sources.

## Members

- **Sora — Weather and Safety Watcher:** owns JMA weather, rain, typhoon, and disaster advisory evidence.
- **Seikatsu — Life Admin Clerk:** owns furusato nozei, postage, zip codes, wareki and rokuyo conversions, holidays, and library searches.

## Included skills

- **Japan Weather and Safety Brief:** turns JMA bulletins into plain-language daily guidance with issuance times.
- **Japan Life Admin Errands:** answers rule-governed questions with the formula, inputs, and public source.

## Helpful connections

No connection is required; all sources are public. Calil library search is optional and uses the user's own free API key, connected inside OpenMausBot. This package contains no credentials.
