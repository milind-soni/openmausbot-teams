## Bot

- **Colin — 软件开发助手**

## Skills

- **code-review:** Review the changes since a fixed point (commit, branch, tag, or merge-base) along two axes: Standards (does the code follow this repo's documented coding standards?) and Spec (does the code match what the originating issue/spec asked for?). Runs both reviews in parallel sub-agents and reports them side by side. Use when the user wants to review a branch, a PR, work-in-progress changes, or asks to "review since X".
- **coding-colin:** Apply project-aware coding standards and modular architecture when writing, changing, refactoring, or reviewing software. Select Go, Dart/Flutter, Vue, React/TypeScript, or Python guidance based on the actual files and stack; preserve existing project rules and behavior.
- **ponytail-review:** Quality review of a change: is the logic right, is it safe, does it hold under real load, is risky code tested, is it fast enough, and is every line needed. Reads the connected code, not only the diff. Each finding is explained in plain English. Use for "review this", "code review", "review the last commit", "review my PR", "is this over-engineered", /ponytail-review.

Add it in MausBot with Import… and this folder's link. Routines arrive paused, and you connect your own apps.
