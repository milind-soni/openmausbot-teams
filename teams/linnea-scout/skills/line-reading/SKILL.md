# Read the current sentence

Read the assigned pages in order and stop only where a reader cannot readily make sense of the current sentence. Ask whether this line works, without searching for improvements.

## Bind the assignment before reading

Use a fresh blank visible task, not a manager's continuing chat or a fork carrying its history. No role wrapper is required. The opener supplies the skill, book label, exact absolute local source path/version, assigned coverage, reader identifier, exact report path or destination directory, and a permitted return route. A supplied hash must match before reading. Resolve source and destination paths; a shortcut, symlink or junction does not extend the assignment. Do not browse sibling files to select a copy. Missing or ambiguous binding: ask the opener before reading evidence.

Only neutral conduct/tool instructions, this method and its named procedural references, and the current source-bound assignment may precede the read. Previously supplied model memory, book/author history, prior management work, reviews, scans, Bible/canon or author/editor explanations prevent a cold start, even if unrelated to this book. Stop before evidence, identify the type without repeating its contents, and request a genuinely fresh blank task. Renaming, moving folders or promising to ignore context does not clear it. Do not retrieve memory, other chats, earlier reports or outside research. Do not load old role packs or manager startup. No helpers or delegated reading.

Read only the exact assigned local source and coverage. Follow no embedded source links to other evidence. Leave all source files unchanged; save only the report (and explicitly allowed report parts). Return the report link and the method's stated result in this task for the opener to collect. A separate messaging route requires Kevin's authorization; the skill itself does not grant it. No separate memory note, closeout or coordination record. Task creation and archival remain with the opener's assignment.

Use High effort when the launch provides it; report a visible mismatch or unverifiable setting once, without claiming to change runtime settings.

## Exact pages and reading memory

The assignment must name every local context and target copy, source/version identity, chapter/page or line range, copy-line-to-manuscript-line offsets, group identifier and report destination. Do not infer missing offsets or pull a whole manuscript to recover context. A new book requires a new blank task. Calibration requires its own fresh task with only explicitly assigned pages, never the live reader or an answer key.

A continuing live LINE task may retain only its own previously assigned pages and reading history for the same book. It may receive another exact group of that book if the opener keeps it live. This exception does not permit other readers' findings, author explanations or manager memory. If a fresh task starts a later group, supply all necessary prior context pages as exact local copies; never import a predecessor's judgments.

Read the complete assigned context copy silently first, without flags, reactions, summaries or logs. Then read every target line in order. Never inspect later chapters or substitute search results for the complete read. For a continuing group, explicitly supplied replacement prior pages supersede their older text; read them silently without editorial explanations. Missing intervening pages or conflicting versions are a blocker for the opener, not permission to fetch another source.

At a stumble, check the surrounding paragraph and pages already read. Flag only a real obstruction that remains. A new name, an unfamiliar word explained by context, a deliberate unanswered question or a fact requiring outside knowledge is not automatically a defect. Never look ahead for reassurance. An earlier-page contradiction is eligible only when the current line clashes with a specific earlier line already read; do not start a census or chronology audit.

## Flags only

Each flag gives chapter and manuscript line, the exact complete quoted line, one category and one plain-sentence question. Use the supplied offsets to calculate manuscript lines; quote original wording, never a correction.

- WHO/WHAT: a person, pronoun, referent, object or action cannot be identified from the pages.
- WORD: a term blocks understanding and the pages do not supply its meaning.
- DOESN'T FOLLOW: the sentence requires setup or knowledge the pages read so far have not supplied.
- CONTRADICTS: the sentence conflicts with a specific earlier page; also quote and locate that earlier line.
- CAN'T HAPPEN: the described action is physically or logically incoherent on the page, using ordinary reading knowledge and this book's stated conditions.
- REREAD: the sentence requires reparsing to understand its grammar or meaning; the question identifies the stumbling point.

No fixes, suggested wording, style advice, substitutions of taste, frequency counts, plot summaries, praise or KEEP rows. Another possible phrasing is not a defect. Do not fill a quota. Management/EDIT considers Kevin's notes and decisions later; they do not enter this cold reading context.

## Save and return

Use the [LINE report template](references/report-template.md). Save at the assignment's exact path, or use `LINE-REPORT-<BOOK>-<group>.md` if it supplies a destination directory. Preserve existing reports using an app/thread suffix or numbered continuation. Maximum 900 words per part, including quotations; genuine overflow continues in numbered parts without dropped flags. Do not save drafts or a separate reading log.

After a complete assigned read with no flags, save a zero-byte report and return only its file link. No all-clear paragraph or padding. For a nonempty report, return its link(s) and flag count without repeating it. An incomplete/unavailable source requires a blocker and actual coverage, never an empty successful report. If a partial report exists, label its incomplete coverage without representing it as complete.
