# Proof the finished PDF

This method is finished-PDF proof after layout within an assigned COMPLETE/KDP workflow. It does not perform initial manuscript proof, certify CHECK's before/after edits or grant release approval. If given Markdown, DOCX, an unfinished manuscript or an ambiguous proof stage, return the scope mismatch before reading and ask for the exact finished PDF assignment.

## Bind the assignment before reading

Use a fresh blank visible task, not a manager's continuing chat or a fork carrying its history. No role wrapper is required. The opener supplies the skill, book label, exact absolute local source path/version, assigned coverage, reader identifier, exact report path or destination directory, and a permitted return route. A supplied hash must match before reading. Resolve source and destination paths; a shortcut, symlink or junction does not extend the assignment. Do not browse sibling files to select a copy. Missing or ambiguous binding: ask the opener before reading evidence.

Only neutral conduct/tool instructions, this method and its named procedural references, and the current source-bound assignment may precede the read. Previously supplied model memory, book/author history, prior management work, reviews, scans, Bible/canon or author/editor explanations prevent a cold start, even if unrelated to this book. Stop before evidence, identify the type without repeating its contents, and request a genuinely fresh blank task. Renaming, moving folders or promising to ignore context does not clear it. Do not retrieve memory, other chats, earlier reports or outside research. Do not load old role packs or manager startup. No helpers or delegated reading.

Read only the exact assigned local source and coverage. Follow no embedded source links to other evidence. Leave all source files unchanged; save only the report (and explicitly allowed report parts). Return the report link and the method's stated result in this task for the opener to collect. A separate messaging route requires Kevin's authorization; the skill itself does not grant it. No separate memory note, closeout or coordination record. Task creation and archival remain with the opener's assignment.

Use High effort when the launch provides it; report a visible mismatch or unverifiable setting once, without claiming to change runtime settings.

## Required PDF binding

The assignment names the finished PDF(s), edition/format, reader number, report destination and COMPLETE/KDP receiving owner. Every permitted PDF must be named explicitly; no outside source or previous proof report may supply an answer. Compute each source's SHA-256 and include it in the report; compare any supplied expected hash. Default reader numbers are Claude 01 and Codex 05 only when no number was assigned. Preserve the assigned number and never overwrite another report.

Use existing local PDF tooling to render and inspect the source faithfully. Read only neutral PDF-tool instructions if needed. No installs, web, external services, helpers, manuscript edits, PDF edits or new layout. The assignment may name a separate scratch directory for rendered pages; these are temporary source derivatives, not additional evidence or deliverables. If the tooling requires persistent render files and no scratch location is permitted, ask for one rather than write elsewhere.

## Read every physical page

Render and read every physical page in order, as a buyer reads the printed book. Extracted text, search hits and contact sheets can assist navigation but never substitute for viewing every page at readable size. Cover front matter, body, blank pages and back matter. Track actual physical-page coverage and every unreadable/unseen page; partial coverage cannot receive a completed-proof result.

Look for layout gaps, stranded single lines, scene breaks lost at page edges, inconsistent chapter openings and crowded/loose lines; folios in sequence and on correct sides; chapter sequence; every contents entry present with the correct real folio; visible typos, missing/doubled words, wrong-facing quotes/apostrophes and stray marks; missing, mismatched or misplaced front/back matter observable within this PDF. Keep physical PDF page and printed folio distinct, including unnumbered pages.

Unusual punctuation used consistently may be deliberate: list it once as a question. No story, style, voice or canon judgments and no invented defect quota. Do not claim hidden production settings, physical print quality or account readiness from PDF appearance.

## Report and finish

Use the [finished-PDF report template](references/report-template.md). Save one non-overwriting report, at most 1,500 words, at the assigned exact path or `PROOF-REPORT-<book>-<nn>.md` in the assigned destination. A collision requires a suffix, never replacing an earlier report. Include the stage, source identity/hash, edition, reader/app/model, date, coverage and all limitations, followed by one findings table. State explicitly when a complete read yields no findings. An incomplete read must be labeled incomplete even if no defects were seen.

If necessary evidence cannot fit in the report limit, tell the opener instead of silently omitting findings or creating extra reports. Return the saved report link and completion/coverage status through the permitted route. COMPLETE/KDP dispositions findings through the authorized source/layout owner, binds any corrected PDF and decides rechecks; this reader neither repairs nor publishes. A clean report is evidence, not a publication authorization.

Only after the report is saved and returned may the opener separately assign a follow-up method; keep this proof report fixed and do not load follow-up material during the proof. Start no next job yourself.
