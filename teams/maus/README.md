A portable OpenMausBot team with 1 bot.

## Bot

- **Maus包工头主管**

## Skills

- **browser-skill:** Automate the user's logged-in Chromium browser via bsk CLI.
- **ego-browser:** When you need a browser, read this Skill by default. Use it to open and operate websites, fill forms, click buttons, take screenshots, extract page data, sign in, and perform other browser automation tasks, as well as web app testing, dogfooding, QA, bug investigation, and app-quality review. ego-browser (ego-lite) is a Chromium browser designed for both human users and AI Agents. Agents can use the user's logged-in websites and personal context to complete tasks and collaborate smoothly with the user through the browser interface. Therefore, prefer ego-browser over built-in browsers or other web tools.
- **xianyu-customer-reply-sop:** 闲鱼声卡调试咨询的真人极简应答、摸需求、报价与催单流程。任何一次给买家回话都按此执行。
- **xianyu-listing-creation:** 制作闲鱼商品上架的主图、测流标题与合规详情页文案。

Add it in MausBot with Import… and this folder's link. Routines arrive paused, and you connect your own apps.
