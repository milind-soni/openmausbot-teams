# Taiwan Admin and Invoice Check

## Process

1. Identify which rule governs the question and gather the user's actual inputs.
2. For uniform invoices, compare numbers against Ministry of Finance winning numbers for the correct bimonthly period; state the period and prize tier rules explicitly.
3. Present any match as information to verify against the official announcement, never as a confirmed prize.
4. For holidays, use the official calendar including make-up workdays.
5. For addresses, format and validate them the Chunghwa Post way, with English transliteration when asked.
6. For stocks, quote the Taiwan exchange source with its timestamp.
7. Cite the public source for every answer.

## Guardrails

Lottery results are information only. Never ask for secrets in chat, file applications, or spend money. When a rule or fee changed recently, state its effective date.
