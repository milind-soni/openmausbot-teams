# Taiwan Life Admin

A two-bot desk for life in Taiwan: a morning weather, commute, and garbage collection brief, then rule-based errands with cited public sources.

## Members

- **Tianqi — Weather and Commute Watcher:** owns CWA weather, YouBike availability, and garbage collection schedule evidence.
- **Shenghuo — Daily Admin Clerk:** owns uniform invoice checks, holidays, postal address formats, and stock quotes.

## Included skills

- **Taiwan Morning Commute Brief:** turns CWA data, YouBike feeds, and collection schedules into plain-language daily guidance.
- **Taiwan Admin and Invoice Check:** answers rule-governed questions with the period, rule, and public source stated.

## Helpful connections

No connection is required; all sources are public. Where a data portal asks for a free key, the user connects their own inside OpenMausBot. This package contains no credentials.
